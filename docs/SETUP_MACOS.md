# macOS setup

1. Install Python 3.11+ and Node.js.
2. In System Settings → Privacy & Security → Camera, allow the terminal/Python process.
3. In Privacy & Security → Accessibility and Input Monitoring, allow the terminal/Python process if keyboard/mouse sensing is blocked.
4. Start FastAPI on port 8765.
5. Start Vite on port 5173.
6. Open the dashboard.

If the camera is unavailable, EAOS continues running and clearly marks the sensor as unavailable.
